# Copilot Proxy (CrawClaw plugin)

Provider plugin for the **Copilot Proxy** VS Code extension.

## Enable

Bundled plugins are disabled by default. Enable this one from Desktop Settings
→ Plugins, then restart the local Gateway from the desktop app.

## Authenticate

Use Desktop Settings → Models to authenticate the `copilot-proxy` provider and
set it as the default model provider.

## Notes

- Copilot Proxy must be running in VS Code.
- Base URL must include `/v1`.
