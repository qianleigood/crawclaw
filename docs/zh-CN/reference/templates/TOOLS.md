# TOOLS.md - 本地笔记

Skills 定义工具的**工作方式**。此文件用于记录**你的**具体情况 —— 属于你独特设置的内容。

## 这里放什么

例如：

- 摄像头名称和位置
- SSH 主机和别名
- TTS 首选语音
- 扬声器/房间名称
- 设备昵称
- 任何特定于环境的内容

## 示例

```markdown
### 摄像头

- living-room → 主区域，180° 广角
- front-door → 入口，动感触发

### SSH

- home-server → 192.168.1.100，user: admin

### TTS

- 首选语音："Nova"（温暖，略偏英式）
- 默认扬声器：厨房 HomePod
```

## 为什么分开？

Skills 是共享的。你的设置是你的。将它们分开意味着你可以在不丢失笔记的情况下更新 skills，在分享 skills 时不会泄露你的基础设施。
