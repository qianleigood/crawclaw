# Channel Troubleshooting

Start from CrawClaw Desktop status and Gateway diagnostics. Channel issues
usually fall into one of four areas: setup credentials, pairing or allowlists,
runtime lifecycle, or routing.

## Checklist

- Confirm the Gateway is running and reachable from CrawClaw Desktop.
- Confirm the channel is configured and enabled.
- Check pairing or allowlist state for the sender or room.
- Check channel lifecycle status and recent logs.
- Confirm the route maps to the intended agent.
