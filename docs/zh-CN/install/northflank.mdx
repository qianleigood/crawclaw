使用一键模板在 Northflank 上部署 CrawClaw，并使用支持的 gateway 客户端连接。这是"服务器端无终端"最简单的路径：Northflank 为你运行 Gateway 网关。

## 如何开始

1. 点击 [Deploy CrawClaw](https://northflank.com/stacks/deploy-crawclaw) 打开模板。
2. 如果你还没有账户，请在 [Northflank](https://app.northflank.com/signup) 上创建一个账户。
3. 点击 **Deploy CrawClaw now**。
4. 设置所需的环境变量：`CRAWCLAW_GATEWAY_TOKEN`（使用强随机值）。
5. 点击 **Deploy stack** 构建并运行 CrawClaw 模板。
6. 等待部署完成，然后点击 **View resources**。
7. 打开 CrawClaw 服务。
8. 使用支持的 gateway 客户端连接到公共 CrawClaw URL，并使用你的 `CRAWCLAW_GATEWAY_TOKEN` 进行认证。

## 你将获得

- 托管 CrawClaw Gateway 网关
- 通过 Northflank Volume（`/data`）实现持久化存储，使配置/凭证/工作区在重新部署后得以保留

## 连接渠道

通过 SSH 运行 CrawClaw Desktop 或本地 Gateway API 获取渠道设置说明：

- [飞书](/channels/index)（最快——只需 Bot Token）
- [QQBot](/channels/index)
- [所有渠道](/channels)
