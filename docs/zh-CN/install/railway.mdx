使用一键模板在 Railway 上部署 CrawClaw，并使用支持的 gateway 客户端连接。
这是最简易的"服务器端无需终端"方案：Railway 为你运行 Gateway。

## 快速清单（新用户）

1. 点击 **Deploy on Railway**（下方）。
2. 添加挂载在 `/data` 的 **Volume**。
3. 设置必需的 **Variables**（至少需要 `CRAWCLAW_GATEWAY_PORT` 和 `CRAWCLAW_GATEWAY_TOKEN`）。
4. 在端口 `8080` 上启用 **HTTP Proxy**。
5. 使用支持的 gateway 客户端连接到 `https://<your-railway-domain>`，并使用你的 `CRAWCLAW_GATEWAY_TOKEN` 进行认证。

## 一键部署

<a href="https://railway.com/new" target="_blank" rel="noreferrer">
  Deploy on Railway
</a>

部署后，在 **Railway → 你的服务 → Settings → Domains** 中找到你的公共 URL。

Railway 将会：

- 为你分配一个生成域名（通常是 `https://<something>.up.railway.app`），或
- 如果你绑定了自定义域名，则使用该域名。

## 你将获得

- 托管式 CrawClaw Gateway
- 通过 Railway Volume（`/data`）实现持久化存储，确保配置/凭证/工作区在重新部署后仍然保留

## 必需的 Railway 设置

### 公共网络

为服务启用 **HTTP Proxy**。

- 端口：`8080`

### Volume（必需）

挂载一个 Volume 在：

- `/data`

### Variables

在服务上设置以下变量：

- `CRAWCLAW_GATEWAY_PORT=8080`（必需 — 必须与公共网络中的端口一致）
- `CRAWCLAW_GATEWAY_TOKEN`（必需；请作为管理员密钥妥善保管）
- `CRAWCLAW_STATE_DIR=/data/.crawclaw`（推荐）
- `CRAWCLAW_WORKSPACE_DIR=/data/workspace`（推荐）

## 连接渠道
