# 平台

CrawClaw Desktop 运行本地 Rust Gateway 网关/运行时。TypeScript 和 JavaScript 仅用于桌面渲染器，而非默认产品运行时路径。

CrawClaw 专注于桌面应用、本地 Rust Gateway 网关、原生插件和本地集成。Linux、macOS 和 Windows 是当前支持的 Gateway 主机目标。

## Gateway 运行时

使用 CrawClaw Desktop 或本地 Gateway API 作为默认运行时所有者。旧的 CLI 管理的 OS 启动路径不再是桌面产品路径的一部分。
